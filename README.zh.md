# Image Flow · 让静态照片活 3 秒

一张照片进去，一段 3 秒的动态影像出来。不是"加滤镜晃一下"，而是真的让画面里的东西按物理规律动起来。

产物：`mp4`（3 秒，带环境音）+ 可选 `webp` 循环图 + 可选多版对比条。

## 核心原则

1. **先看图，再写词**。不 Read 图片就写 prompt 等于闭眼开枪。用 Read 工具打开图片，看清里面有几个人、光从哪来、什么是前景。
2. **prompt 描述"变化"，不描述"画面"**。画面已经在图里了，重复描述会诱导模型重绘，第一帧就不再是你的照片。
3. **动作要小**。3 秒的最佳状态是"你没注意它在动，但盯着看觉得是活的"。一旦有大幅度动作，立刻变成廉价特效。
4. **身份必须锚死**。图生视频最常见的翻车是脸慢慢变成另一个人。每一条 prompt 都要带一致性约束。

## 何时使用

命中即启动：

- 用户给了一张/一批照片，要"动起来""变视频""做个动态效果"
- 要人物有微表情、多人在交谈、风景在流动
- 要循环动图（网页背景、PPT 配图、朋友圈）
- 老照片修复后的"活化"

不适用，直接说明原因：纯文字截图 / PPT 页 / UI 界面 / 图表（动起来只会糊字）、已经带运动模糊的图（会双重模糊）。

## 工作流

> **路径约定**：`$SKILL` 指本技能的绝对路径（加载技能时给出的 Base directory）。脚本用绝对路径调用，中间产物落在用户当前工作目录，不污染技能目录。

### 第 0 步 · 收口参数 + 报成本（必做）

| 参数 | 默认 | 说明 |
|---|---|---|
| 时长 | 生成 4s → 交付裁 3s | 尾巴常有崩坏，裁掉正好 |
| 分辨率 | 1080P | 用户嫌贵/只要预览就 720P |
| 力度 | L2 自然 | 见下文三档力度 |
| 版数 | 1 版 | 用户说"多来几版"才做 A/B/C |
| 落盘 | `./image-flow/` | 当前工作目录下 |

**必须先告诉用户积分消耗再动手**：视频生成会额外扣费（5 秒约 50–100 积分）。批量处理时先说清"共 N 张，预计消耗 N×…"，等用户点头。

### 第 1 步 · 体检

```bash
python3 $SKILL/scripts/probe.py 照片.jpg
```

读它给出的尺寸、比例、EXIF 方向、亮度、推荐参数。两个必须处理的警告：

- `EXIF 方向为 6/8` → 手机竖拍图，先转正，否则出片是横躺的：
  ```bash
  python3 $SKILL/scripts/probe.py 照片.jpg --normalize ./image-flow/fixed.jpg
  ```
- `无法解析尺寸`（HEIC/AVIF）→ 同样用 `--normalize` 转成 JPEG。

### 第 2 步 · 看图定场景

用 Read 打开图片，回答四个问题（心里有答案就行，不用输出）：

1. 画面主体是什么？人 / 多个人 / 空镜 / 城市 / 室内 / 美食 / 动物 / 产品 / 老照片 / 插画
2. 有几个人，各自在什么位置（左/中/右），谁更适合当"主动者"
3. 光从哪来、是什么天气、有没有可动的自然元素（水、树、云、烟）
4. 哪些地方**绝对不能动**（文字、logo、人脸五官、建筑直线）

然后按场景去 `references/motion-library.md` 取动效句。那张表按 10 类场景分好了，每类都有三档力度的现成英文句子和禁忌。

### 第 3 步 · 组装 prompt

按 `references/prompt-recipes.md` 的五段式写：

```
[1 Shot]      镜头怎么动
[2 Subject]   主体做什么（唯一主动者 + 幅度 + 速度）
[3 Secondary] 次级运动（呼吸/发丝/衣料/光影）
[4 Ambient]   环境运动（风/水/云/鸟/人流）
[5 Anchor]    身份与质感约束
```

60–120 个英文单词。**用英文写**，图生视频模型对英文动作词的响应明显更准。负向词直接用配方里的默认串。

### 第 4 步 · 生成

调用 VideoGen，图生视频模式：

| 参数 | 怎么填 |
|---|---|
| `image` | 照片绝对路径（转正后的） |
| `prompt` | 第 3 步的结果 |
| `negative_prompt` | 配方里的负向词，按题材增删 |
| `seconds` | 优先 `4`；模型不接受自定义时长就省略，用默认值 |
| `resolution` | `1080P`，预览用 `720P` |
| `enable_audio` | 人物/实景 `true`；做循环图 `false` |
| `aspect_ratio` | **不要传**，图生视频由图片比例决定 |
| `output_dir` | `./image-flow/` |

需要无缝循环时，把 `last_image` 也设成同一张图（首尾帧锁死，见配方文档）。

生成要 1–3 分钟，**不要重复调用**，等结果。

### 第 5 步 · 质检

按 `references/qa-checklist.md` 扫一遍：首帧是否等于原图、脸有没有漂、手指有没有变多、末帧有没有融化。不达标就降一档力度重跑，别指望"再抽一次卡"。

快速看全片：`python3 $SKILL/scripts/finish.py sheet 成片.mp4 -o 质检.jpg`

### 第 6 步 · 收尾交付

```bash
# 裁到 3 秒
python3 $SKILL/scripts/finish.py trim 成片.mp4 -o final.mp4 -d 3
# 无缝循环版（正放+倒放）
python3 $SKILL/scripts/finish.py loop final.mp4 -o loop.mp4
# 网页/微信用的动图（webp 比 gif 小 60%）
python3 $SKILL/scripts/finish.py gif final.mp4 -o final.webp --webp --width 600
```

交付三件套：`final.mp4`（3 秒）+ `loop.mp4`（循环）+ `final.webp`（轻量）。用 present_files 一次性给用户。

## 场景速查

| 画面里有什么 | 动什么 | 一句话 |
|---|---|---|
| 单人 | 呼吸、眨眼、发丝、极缓推近 | 人不动，气氛在动 |
| 多人 | **一个人说话**，其他人点头微笑，视线交换 | 只许一个主动者 |
| 空镜风景 | 树叶摇曳、水波流动、云飘、鸟飞过 | 横移比推近更有呼吸感 |
| 城市 | 车流、行人、霓虹闪、云影过楼 | 建筑直线必须锁死 |
| 室内 | 窗帘、尘埃光柱、烟雾、窗外光影 | 极缓推近就够 |
| 美食 | 热气升腾、油光流动、冷凝水 | 食物形状不能变 |
| 动物 | 呼吸、耳朵尾巴、眨眼、毛发 | 别让它走路 |
| 产品 | 高光扫过、微旋转、背景光斑 | 文字 logo 必须清晰 |
| 老照片 | 微动 + 胶片颗粒闪烁 | 机位几乎不动 |
| 插画 | 同真实题材，但风格要写死 | 最怕被"真人化" |

## 创新玩法（用户说"有啥想法"时主动提）

1. **一图多版**：同一张图跑三种运镜（推近 / 横移 / 环绕），用 `finish.py compare a.mp4 b.mp4 c.mp4 -o 对比.mp4` 拼成对比条让用户挑。成本翻倍，所以先问。
2. **首尾帧闭环**：`image` 和 `last_image` 都传原图，模型被迫"出去再回来"，得到天然可循环的 3 秒。
3. **3 秒讲一段时间**：prompt 里让光线变暖、影子变长，观感比单纯晃动高级一档。
4. **微事件彩蛋**：只发生一次的小事件——一只鸟掠过、一片叶子落下、有人从窗外走过。一个就够，多了变杂耍。
5. **声音层**：实景开 `enable_audio`，风声水声人声低语会把"动图"直接抬成"短片"；循环图则关掉。
6. **镜头接龙**：`finish.py frame --at end` 抽出末帧 → 当新首帧再生成 → `finish.py concat --fade 0.15` 接起来，做 6–9 秒慢长镜。
7. **情绪三档**：同一张图分别出 L1 微动 / L2 自然 / L3 戏剧，给用户选"要多活"。

## 边界与实话

- 视频模型不会写字，原图里的招牌/logo 可能被改写，交付前要检查。
- 老照片里的人物五官本就模糊，动起来会有轻微失真，这是物理限制，提前说清楚。
- 多人远景（人脸很小）不要做口型，会糊成一片，只写"轻微转头"。
- 人脸特写不要做大幅转头或大笑，几乎必崩。
- 视频生成耗时 1–3 分钟，批量时按顺序来，别并发轰炸。

## 脚本

| 脚本 | 干什么 |
|---|---|
| `scripts/probe.py` | 生成前体检：尺寸/比例/EXIF 方向/亮度/细节量 → 推荐参数；`--normalize` 转正转码 |
| `scripts/finish.py` | 生成后收尾：`info` `trim` `loop` `fade` `gif` `frame` `sheet` `compare` `concat` `speed` |

`finish.py` 依赖 ffmpeg。找不到时它会自动去 `FFMPEG_BINARY`、imageio-ffmpeg 自带二进制、Homebrew 路径里找；仍然没有就提示 `brew install ffmpeg` 或 `pip install imageio-ffmpeg`。
